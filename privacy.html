Privacy Policy — Colorquake Uploader

Last updated: November 25, 2026

What this application is

Colorquake Uploader is a personal, single-user tool operated by the owner of the YouTube channel Colorquake. It is used only to manage the owner's own YouTube channels through the official YouTube Data API.

Data the application accesses

With the channel owner's explicit authorization (OAuth), the application accesses the YouTube Data API to upload videos, set custom thumbnails, edit video titles, descriptions and visibility, manage playlists, and post comments on the owner's own channels. The application does not access data belonging to any other person.

How data is stored

OAuth access and refresh tokens are stored only on the owner's own computer, in files with restricted permissions. No channel data or token is stored on external servers, and no analytics or tracking is performed.

Sharing

No data obtained through the YouTube Data API is sold, rented, shared, or disclosed to any third party.

Revoking access

Access can be revoked at any time from the Google account permissions page: https://myaccount.google.com/permissions — after revocation the application can no longer access the channel.
